## Adding an artifact

1. Create a lowercase, hyphenated folder under the appropriate course's `artifacts/` directory.
2. Add its `index.html`, images, and downloadable deliverables to that folder.
3. Include title, introduction, description, objective, process, tools and technologies, value proposition, unique value, relevance, and references as applicable.
4. Add a linked summary card to that course's index page.
5. Reuse `assets/css/styles.css` and load only the scripts the page needs.
6. Check navigation, relative asset paths, and mobile layout before publishing.

This is a static GitHub Pages website; no build step is required. Paths are relative so the site works under the repository's project URL.
