A feedforward classifier with two hidden layers

A map of the six components

I grouped components by their role in prediction and learning.

Architecture

Layers and neurons

Organize the network and perform its computations.

Learned parameters

Weights and biases

Control the strength and offset of each calculation.

Transformation

Activation functions

Turn weighted sums into values for the next layer.

Learning

Loss and optimization

Measure errors and update the parameters.

This grouping separates structure, adjustable values, transformations, and training rules. The categories describe functions, so related components still interact.

Sources: Google, 2025a, 2025b; TensorFlow, n.d.-a, n.d.-b, n.d.-c. See References for links.

Layers organize the flow of data

Input layer

Receives the selected features, such as x₁ and x₂.

Hidden layers

Transform earlier outputs into useful intermediate features.

Output layer

Produces a prediction score from the final hidden outputs.

Illustrative 2–4–2–1 architecture matching Run A. Data flows from left to right. Two hidden layers plus one output layer contain learned parameters.

Sources: Google, 2025a, 2025b; TensorFlow, n.d.-a, n.d.-b, n.d.-c. See References for links.

A neuron combines weights and an activation

Weights scale each input

z = w₁x₁ + w₂x₂ + b
z = 0.8(0.5) + (−0.4)(−1) + 0.2 = 1.0

Activation transforms the sum

a = tanh(z) = tanh(1.0) ≈ 0.762
A bias shifts the activation threshold independently of the inputs.

Illustrative values, not values extracted from the experiment. A positive weight increases z for a positive input. Its effect also depends on the input’s sign.

Weights and biases are learned during training. Learning rate and layer sizes are settings we choose.

Sources: Google, 2025a, 2025b; TensorFlow, n.d.-a, n.d.-b, n.d.-c. See References for links.

Activation functions enable nonlinear patterns

ReLU returns zero for negative inputs and grows linearly for positive inputs. Common in hidden layers.

Tanh maps values into (−1, 1). The experiments use tanh or linear hidden activations.

Sigmoid maps values into (0, 1). Often used for a binary probability output with an appropriate loss.

Stacked linear hidden layers remain affine in the selected features. Nonlinear features can also make a curved boundary possible in the original coordinates.

Playground’s classification output uses tanh even when the hidden activation is Linear. Its signed score is not a calibrated probability.

Sources: Google, 2025a; TensorFlow, n.d.-b, n.d.-c. See References for links.

Loss turns prediction error into a training objective

A loss function assigns a numerical penalty to a prediction.

L = (1/n) Σ ½(ŷᵢ − yᵢ)²

This is Playground’s average half-squared error. Smaller values mean better agreement with the target scores on that dataset.

The target labels are −1 and +1. A loss of 0.016 does not mean 98.4% accuracy.

One illustrative prediction

Target y = 1
Prediction ŷ = 0.6
Error = −0.4

½(0.6 − 1)² = 0.08

Averaging these penalties over the examples gives the reported loss.

Training loss measures the examples used to update parameters.

Test loss checks held-out examples. Repeated tuning against it reduces its independence.

Other tasks use other objectives, such as cross-entropy for classification or mean squared error for regression. The loss must match the output representation and task.

Sources: TensorFlow, n.d.-b, n.d.-c. See References for links.

Optimization updates weights and biases

An optimization algorithm uses gradients to reduce the loss.

wnew = w − η ∂L/∂w

η is the learning rate. Backpropagation calculates gradients using the chain rule. The optimizer applies the update.

Illustration: w = 1, η = 0.03, gradient = 0.4
wnew = 0.988

Mini-batch gradient descent averages gradients over a small batch. Playground uses this approach with batch size 10 here.

Adam uses moving estimates of gradients and squared gradients to adapt updates. It is an alternative, not an optimizer tested in these runs.

Sources: TensorFlow, n.d.-b, n.d.-c, n.d.-d. See References for links.

Prediction and learning form a feedback loop

Forward

Layers pass activated values toward the output to calculate a prediction.

Backward

The loss provides the starting derivative. Backpropagation attributes gradients to earlier parameters.

Update

The optimizer changes weights and biases. Repeated batches gradually change the boundary.

Inference uses the forward pass. Training adds target labels, loss, gradients, and parameter updates.

Sources: TensorFlow, n.d.-b, n.d.-c. See References for links.

Six recorded runs with a common training budget

Settings held constant

  • Classification and 50% train / 50% test split
  • 100 epochs per run and batch size 10
  • Learning rate 0.03 and no regularization
  • Displayed seed parameter 0.49259
  • Tanh output and average half-squared loss

Settings varied

  • Circle and XOR data
  • Noise 0 and 50
  • Raw coordinates and squared features
  • Tanh and linear hidden activation
  • Two hidden layers [4, 2] and one [1]

I recorded the interface at 100 epochs rather than timing browser automation. Epochs measure training progress, while parameter counts describe part of the computational cost.

Single illustrative runs, not repeated benchmarks. Configuration changes reset training and can change initialization. A shared seed setting does not guarantee identical starting weights across different structures. The recorded screenshots preserve the outcomes of these particular runs.

Sources: Experiments recorded in TensorFlow Playground, November 2, 2026. See References for links.

Nonlinear hidden neurons learned the circle

With raw x₁ and x₂, Run A learned a closed boundary. Run B stayed near 0.500 test loss despite the same layer sizes.

The final tanh output can squash a linear score, but its zero-level decision boundary remains a line when all hidden transformations and inputs are linear.

Sources: TensorFlow Playground screenshots, November 2, 2026. See References for links.

Squared features exposed the circular structure

x₁² + x₂² describes squared distance from the origin.

r² = x₁² + x₂²

Adding x₁² and x₂² gave the model the ingredients for a radial boundary. Test loss fell from 0.500 in B to 0.001 in C.

Four inputs also increased the parameter count from 25 to 33, so representation and parameter count both changed.

Feature engineering can simplify the relationship the network must learn.

Sources: Original Playground observations. See References for links.

Noise and dataset geometry changed the outcome

Noise: D’s training loss 0.300 and test loss 0.327 both exceed A’s. Overlapping classes make separation harder. This alone does not establish overfitting.

Geometry: E reached 0.115 test loss at 100 epochs. The same architecture and budget did not produce the same loss on another data arrangement.

Sources: Original Playground observations. See References for links.

A smaller model reduced cost and capacity

5 parameters versus 25 in the baseline

Run F reached test loss 0.434, compared with 0.016 in A. One hidden neuron could not surround the inner class.

More parameters require more arithmetic per update and can represent more complex functions. They also introduce more opportunities to fit noise.

Match capacity to the task. More layers do not automatically improve generalization.

This comparison changes depth and width together. It cannot identify their separate effects. No wall-clock speed benchmark, repeated seeds, or independent validation study was performed.

Seeing the network made its tradeoffs clearer

Structure

Layers organize neurons. Weights and biases control their calculations. Activations determine the transformations they can express.

Learning

Loss measures errors, backpropagation calculates gradients, and optimization changes the parameters.

Evidence

Features, activation, capacity, and data quality all changed the recorded outcomes. A useful boundary depends on their combination.

Visualization makes these relationships visible and helps explain why a model succeeds, stalls, or fits the wrong pattern.
