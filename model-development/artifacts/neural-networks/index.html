Visualizing Neural Networks

A 16-slide visual guide explaining layers, neurons, weights, activation functions, loss functions, and optimization algorithms. Original diagrams connect these components to six recorded TensorFlow Playground experiments.

Arvinnd Chowdary Kuchipudi
AIML-501 Model Development · Indiana Wesleyan University · November 2, 2026

Understand the components

A role-based map, a worked neuron calculation, activation curves, and a training feedback loop.

Compare the experiments

Circle and XOR datasets with changes to activation, features, noise, and model capacity.

Interpret the evidence

Recorded training and test losses, actual screenshots, parameter counts, and clear limitations.

Objective
Make neural network behavior understandable to students, software professionals, and people making practical AI decisions.
Process
Group components by function, illustrate their relationships, conduct six 100-epoch Playground runs, and connect the observations to model choices.
Tools
TensorFlow Playground, its open-source implementation, original SVG diagrams, HTML, CSS, and JavaScript.
Value Proposition
I combine software-development reasoning with visual explanations and recorded experiments to help learners connect neural network terminology to model behavior and make better-informed design choices.

Context, challenge, and solution

The first Model Development artifact compares algorithm families. This second artifact examines how a neural network works internally. The challenge was to simplify the concepts without confusing prediction scores, error measurements, and parameter updates. A consistent architecture diagram and role-based grouping keep the explanation clear, while six experiments supply concrete evidence.

Unique value and professional relevance

This artifact connects component definitions with practical tradeoffs in input representation, nonlinear transformations, capacity, and data quality. It demonstrates my ability to explain technical decisions to both technical and nontechnical audiences, complementing my software development background.

Skills demonstrated

Neural network fundamentals, feature engineering, experimental comparison, parameter counting, source verification, visual communication, SVG diagrams, and accessible web presentation design.
